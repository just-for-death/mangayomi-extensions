# Mangayomi Extensions

Custom and community Mangayomi JavaScript extensions repository maintained by [just-for-death](https://github.com/just-for-death).

## Repository URL
Add this URL into Sunfire or Mangayomi under **Settings > Extension Repositories**:

```text
https://raw.githubusercontent.com/just-for-death/mangayomi-extensions/main/index.json
```

## Extensions Included
* **Mangago (EN)**: JavaScript scraper for `https://www.mangago.me` with Popular, Latest, Search, and Chapter Reader support.
